# Documentation

## Rôle et responsabilités

- Conserver les standards et explications durables du projet.
- Orienter vers une source de référence unique pour chaque convention.

## Conventions techniques

- Les standards Nuxt existants restent dans `2.architecture/`, sans migration générale de leur structure.
- Les règles du cadre IA propres au projet résident dans `AGENTS.md`, les procédures dans les skills. Les conventions exécutables et les commandes sont décrites dans `codebase-integrity/README.md`.
- Les README de code conservent leurs responsabilités et conventions locales. Les cartes conservent les décisions, preuves et verdicts, sans recopier les guides.
- Les vérifications documentaires AIDE portent sur les fichiers de gouvernance, les README de l’outillage, les modèles et les demandes/cartes AIDE, pas rétroactivement sur tous les documents historiques.
- Une modification de cette portée est une consolidation explicite ; ne pas masquer un échec en ajoutant une exclusion ponctuelle.
